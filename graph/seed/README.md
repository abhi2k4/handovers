# graph/seed/

| Path | What |
|---|---|
| `northwind/org.json` | The synthetic company: people, teams, managers, accounts |
| `northwind/sources.jsonl` | Work records with the facts extracted from them |
| `northwind/interview.json` | Scripted exit-interview answers for the demo |
| `northwind/benchmark.json` | Questions and expected sources for `bench.run` |
| `northwind/samples/` | Files to try on the upload screen |
| `interview_bank.json` | Interview questions per skill, for the interview kit |

`northwind/` is generated by `app/backend/seed/` ([README](../../app/backend/seed/README.md)); do not
edit it by hand. `interview_bank.json` is written by hand.
