# app/frontend/src/components/

| File | What |
|---|---|
| `ui.tsx` | Shared primitives: Card, Button, Chip, Input, Modal, Segmented, PageHeader, skeletons ... |
| `icons.ts` | Phosphor icons, one import per icon (keeps the dev server fast) |
| `PlatformLogo.tsx` | Platform and sign-in logos (Simple Icons paths, CC0; Microsoft and Google marks) |
| `ComingSoon.tsx` | Cards for planned connectors and sign-in providers |
| `SignInSettings.tsx` | Integrations → Sign-in: turn providers on or off, sync people |
| `ViewAs.tsx` | The guest "View as" picker and the signed-in identity panel |
| `Xray.tsx` | Graph X-ray: the queries behind a screen and the graph around its subject |
| `TechGraph.tsx` | "How it's built": the project's architecture graph from FalkorDB |
| `Copilot.tsx`, `CommandMenu.tsx`, `Tour.tsx` | Search bar, Ctrl/⌘ K menu, first-visit tour |
| `Readiness.tsx`, `Backups.tsx`, `RampPlan.tsx` | Handover readiness, backup owners, ramp-up plan |
| `StatBand.tsx`, `TrendCards.tsx`, `charts.tsx`, `Pager.tsx` | KPI tiles, trends, charts (column, stacked bar, donut, gauge, bars with target, pipeline steps, sparkline), pagination |
